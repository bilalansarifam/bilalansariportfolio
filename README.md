# Bilal Ansari — Digital Signature Portfolio 

Fresh HTML/CSS/JavaScript portfolio with a PHP contact endpoint and a redesigned selected-work/case-file section.

## Run locally
Open `index.html` for the frontend. The PHP contact form requires a PHP-capable server.

## Build notes
- `css/` contains the visual system, components, sections, motion and responsive rules.
- `js/` contains navigation, cursor, scroll reveals, technology interactions and contact behavior.
- `php/send-mail.php` handles contact submission; configure mail transport on the server rather than storing credentials in source.
- The selected-work section distinguishes project work from professional practice and avoids invented client metrics.
